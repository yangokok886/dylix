## 1.0.4 · Build 135 · 2026-10-30

1. AI 可切换 SDK 16.4 / 26.0 与最低系统版本，保留项目其他配置。
2. AI 可按构建编号清理指定产物，源码与会话记录保留。
3. 会话文件显示修改时间和构建编号，优先展示近期内容。

5. 构建结果返回实际 SDK 和最低系统版本，完善工具说明与权限检查。
